# Calorie Wallet

Dein persönliches Online-Banking für Ernährung.
Keine Moral. Kein Lebensmittel ist gut oder schlecht – manche kosten einfach mehr vom Budget.

## Features

- Wochenbudget statt Tageslimit (Wochenlohn)
- Buchungen statt Mahlzeiten
- Investments (Protein, Kohlenhydrate, Fett, Ballaststoffe)
- Kontoauszug mit Tagesübersicht + Übertrag
- Open Food Facts Produktsuche
- Barcode-Scanner (mobile_scanner)
- Persistente Speicherung (Hive)
- Hell- und Dunkelmodus

## APK bauen ohne PC (privates GitHub)

1. Bei GitHub ein **privates** Repository anlegen (z.B. `calorie-wallet`)
2. Den Inhalt dieser ZIP-Datei in das Repo hochladen
3. Im Repo → Tab **Actions** → Workflow **Build APK** → **Run workflow**
4. Nach ca. 5–10 Minuten unter **Artifacts** die Datei `calorie-wallet-apk` herunterladen
5. ZIP entpacken → `app-release.apk` auf dem Handy installieren

Das Repo ist privat → Code und APK sind nur für dich sichtbar.
